# MĀORI

> A web-based educational platform designed to provide interactive
> learning, user authentication, quizzes, and educational content.

## 🚀 Features

- User registration and login
- User authentication
- Educational content
- Interactive quizzes
- Product/content management
- PHP and MySQL backend
- Responsive web interface

## 🛠️ Technologies

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- XAMPP

## 💻 Running Locally

### Prerequisites

- XAMPP
- PHP
- MySQL
- Web browser

### Setup

1. Install and open XAMPP.
2. Start **Apache** and **MySQL**.
3. Place the MĀORI project inside:

```text
C:\xampp\htdocs\MAORI\

5. Create the required MySQL database using phpMyAdmin.
6. Configure the database connection in `config.php`.
7. Open the application in your browser:

```text
http://localhost/MAORI/
